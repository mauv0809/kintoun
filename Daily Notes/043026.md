impl FromStr for Command {
    type Err = ParseError;

    fn from_str(input: &str) -> Result<Self, Self::Err> {
        // Step 1 — tokenize. split_whitespace() handles runs of spaces/tabs/newlines
        //          and trims leading/trailing whitespace for free.
        let mut parts = input.split_whitespace();

        // Step 2 — pull the verb. None means input was empty/whitespace-only.
        //          .ok_or(...) converts Option<T> -> Result<T, E>; ? unwraps Ok or returns Err.

**New syntax glossary:**
- `?` — postfix on `Result`; unwraps `Ok` or returns `Err` early from the enclosing fn.
- `.ok_or(err)` / `.ok_or_else(|| err)` — `Option<T>` → `Result<T, E>`. The `_else` form is lazy.
- **Binding in match arms** — `unknown =>` binds the unmatched value to the local `unknown`.
- **Field shorthand** — `Command::Incr { key, by }` ≡ `Command::Incr { key: key, by: by }`.
