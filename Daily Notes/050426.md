# 050426 - Daily Work Log

## Decisions
- StoredValue tagged enum (Str/Int) over String-only storage — preserves type-system honesty + future-proofs M4+ variants. ADR 0008.
- Executor-level inference via StoredValue::from_text (not parser-level, not storage-level coercion) — keeps parser pure, storage strict, single source of truth for the rule. ADR 0008.
- ExecuteResult shaped by command class (Mutation/Read/Existence) over flat enum — avoids enum mirroring with MutationOutcome, two-level exhaustiveness. Per ADR 0008.
- cargo-deny over cargo-audit for license + advisory CI; permissive license allowlist (no MPL/LGPL/GPL); `unused-allowed-license = "allow"` to keep allowlist forward-looking. ADR 0009.
- REPL output format: Redis-like (OK / (nil) / quoted Str / bare numbers / 1-0 for existence). EOF-only quit. Errors to stdout with `ERR ` prefix. Formatter as private fn in repl.rs. ADR 0010.
- anyhow at REPL boundary, thiserror at library layers — codified as a project convention for M2+ async code. ADR 0010.
- cargo-llvm-cov over cargo-tarpaulin (LLVM-based, accurate branch coverage, modern Rust default). No threshold yet — measure first, ratchet at M3. ADR 0011.
